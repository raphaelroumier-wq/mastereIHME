# Application de réservation de vélos

## Présentation

Cette application permettra aux utilisateurs de réserver des vélos sur des créneaux horaires définis.

## Objectifs

- Consulter les vélos disponibles.
- Choisir une date et un créneau horaire.
- Réserver un vélo.
- Consulter et gérer les réservations.

## Technologies

- Visual Studio Code pour le développement.
- Git et GitHub pour la gestion du code source.
- Docker Compose pour lancer les différents services de l'application.

## État du projet

Projet en cours de développement dans le cadre d'un travail de cours.
